
### **1. Given Information**

From the problem, we have the following values:

* **Current Function ($I(t)$):** $2\sin(120\pi t)$ A
* **Resistance ($R$):** $50\,\Omega$

### **2. The Formula**

To find the voltage across a purely resistive component in an AC circuit, we use Ohm's Law, which applies instantaneously at any given time $t$:


$$V(t) = I(t) \times R$$

### **3. The Calculation**

Substitute the given values into the equation:


$$V(t) = (2\sin(120\pi t)) \times 50$$

Multiply the constant amplitude of the current (2) by the resistance (50):


$$V(t) = 100\sin(120\pi t)$$

### **Final Answer**

The equation for the voltage across the resistor is:


$$V(t) = 100\sin(120\pi t)\text{ V}$$
